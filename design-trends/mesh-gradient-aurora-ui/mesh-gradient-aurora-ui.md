# Mesh Gradient / Aurora UI design style

Atmospheric multi-point gradients blending luminous colors into soft clouds, glows, and color fields.

## Design overview

## History and origins

A fact-checked account of where this visual language came from, with links to the references used.

Mesh Gradient and Aurora UI are descriptive contemporary labels rather than a documented movement with a single origin. They extend a much older graphic technique—continuous color transition—using modern vector and browser tools to overlap multiple gradient fields; their prominence rose alongside the saturated gradient rebrand cycle of the late 2010s.

## Design principles and implementation

Use these principles to write a focused AI UI design prompt instead of asking for a vague visual treatment.

Blend three to five neighboring luminous hues through soft multi-point fields, preserving quiet dark or pale zones behind important text. In a daisyUI theme, use the gradient's dominant luminous hue for `primary`, its nearest contrasting neighbor for `secondary`, and sample quiet near-white or deep-charcoal tones for the solid `base-100`, `base-200`, and `base-300` surfaces.

Treat the gradient as primary atmosphere, then layer silhouettes, crisp product captures, or simple cutouts rather than competing full-color photography.

Keep gradient-heavy regions sparse and cinematic; move detailed features, forms, and data into visually settled sections.

Drift color clouds slowly through position and blur changes, stopping movement near reading tasks and honoring reduced-motion preferences.

Echo the color fields with broad rounded frames, diffuse halos, and occasional soft blobs while keeping functional controls geometrically clear. In daisyUI themes, set the `--radius-*` variables between `0.75rem` and `1.5rem`.

Use a contemporary sans-serif with large, compact headlines and plain body text; never fill paragraphs or small labels with the gradient.
