# Low-Poly UI design style

Faceted geometric models, simplified shading, angular silhouettes, and deliberately economical three-dimensional detail.

## Design overview

## History and origins

A fact-checked account of where this visual language came from, with links to the references used.

Low-poly imagery began as a technical necessity: mid-1990s consoles and personal computers could render only limited polygon counts in real time. As hardware improved, visible facets shifted from constraint to deliberate style, and 2010s games, illustration, and UI reused the geometry for clarity, nostalgia, and inexpensive motion.

## Design principles and implementation

Use these principles to write a focused AI UI design prompt instead of asking for a vague visual treatment.

Use a limited flat-shaded palette with distinct light, mid, and shadow faces; avoid smooth gradients that erase facet structure. In a daisyUI theme, use the hero object's dominant facet hue for `primary`, a contrasting object or environment hue for `secondary`, and map neutral light, mid, and shadow-face colors to `base-100`, `base-200`, and `base-300`.

Choose polygonal characters, terrain, products, and icons with economical detail and a consistent face count and lighting model.

Keep density low to medium, using large visual regions and concise annotations rather than intricate controls over the model.

Rotate models in measured steps, shift lighting across facets, and transition geometry through crisp folds or controlled vertex movement.

Favor triangles, chamfered cards, angular cutouts, and crystal-like silhouettes with deliberately visible planar changes. In daisyUI themes, set the `--radius-*` variables to `0` or `0.25rem`.

Use an angular geometric display face for headings, pair it with a plain sans-serif for explanation, and avoid faceting small text.

### Cyberpunk UI design style

Dense dark interfaces use neon accents, glitches, terminal typography, surveillance motifs, and futuristic HUD elements.

### Historical Manuscript Skeuomorphism UI design style

A tactile interface style that makes digital UI feel like a physical artifact from an older era, using the visual language of parchment, ledgers, bound folios, and ceremonial documents. It belongs to the broader skeuomorphic tradition, but with a specifically archival, literary, and old-world character.

### Retro Computing UI design style

CRT glow, bitmap fonts, window chrome, limited palettes, scanlines, floppy-disk motifs, and vintage operating-system conventions.
