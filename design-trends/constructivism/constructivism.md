# Constructivism UI design style

Dynamic diagonals, photomontage, bold sans-serif type, limited red-black palettes, and propagandistic visual force.

## Design overview

## History and origins

A fact-checked account of where this visual language came from, with links to the references used.

Constructivism emerged from the Russian avant-garde around the 1917 Revolution. Artists including Aleksandr Rodchenko and Varvara Stepanova rejected autonomous art in favor of production, communication, and social use, developing dynamic diagonals, photomontage, geometric structure, and forceful typography that later became common references in posters and interface graphics.

## Design principles and implementation

Use these principles to write a focused AI UI design prompt instead of asking for a vague visual treatment.

Work in red, black, and aged cream, with occasional gray photographic tones and no soft decorative palette expansion. In a daisyUI theme, use banner red for `primary`, ink black for `secondary`, and set `base-100`, `base-200`, and `base-300` to aged cream, newsprint beige, and photographic gray.

Use high-contrast photomontage, industrial machinery, workers, crowds, architecture, and paper artifacts cut into dynamic angular arrangements.

Use high visual density and compressed slogan-like copy, organizing secondary facts beneath the dominant propagandistic message.

Use diagonal wipes, stamped entrances, rotating wheels, rapid photomontage cuts, and forceful scale changes with machine-like cadence.

Favor wedges, beams, concentric circles, scaffolding lines, arrows, and hard photographic crops that imply momentum and collective force. In daisyUI themes, set the `--radius-*` variables to `0` or `0.25rem`.

Set bold condensed sans-serif in uppercase, rotate or step short phrases along diagonals, and keep supporting information compact and plainly readable.
