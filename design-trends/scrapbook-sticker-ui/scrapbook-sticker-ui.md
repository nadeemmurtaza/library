# Scrapbook / Sticker UI design style

Stickers, tape, stamps, snapshots, doodles, labels, and layered ephemera create a personal assembled look.

## Design overview

## History and origins

A fact-checked account of where this visual language came from, with links to the references used.

Scrapbooks long predate digital interfaces: 19th-century albums combined clippings, cards, drawings, and personal annotation as assembled records. Sticker UI turns that additive, authored surface into a screen language, shaped more recently by digital journaling, messaging stickers, fandom, and social platforms; it is a contemporary synthesis rather than a single historical school.

## Design principles and implementation

Use these principles to write a focused AI UI design prompt instead of asking for a vague visual treatment.

Begin with warm paper, notebook, or cork neutrals, then add varied sticker colors linked by one recurring ink or tape hue. In a daisyUI theme, use the recurring ink or tape hue for `primary`, one representative sticker color for `secondary`, and set `base-100`, `base-200`, and `base-300` to warm paper, notebook cream, and light cork.

Use snapshot crops, instant-film frames, doodles, ticket stubs, stamps, tape, and user-generated media with believable scale and layering.

Use medium to high personal detail, but separate entries with page margins and keep each handwritten callout short.

Peel stickers, press stamps, slide snapshots under tape, and draw doodles in brief tactile sequences triggered by user actions.

Use die-cut sticker outlines, scallops, torn notes, tape strips, label makers, and imperfect snapshot rectangles. In daisyUI themes, set the `--radius-*` variables between `0.75rem` and `1.5rem`.

Reserve handwriting for annotations and names, set longer content in a readable sans-serif or serif, and vary rotation without harming scan order.
