# Grunge UI design style

Distressed type, scratches, stains, rough textures, muted or dirty color, and irregular layering create worn intensity.

## Design overview

## History and origins

A fact-checked account of where this visual language came from, with links to the references used.

Visual grunge developed alongside alternative music but was not confined to Seattle or album packaging. Distressed type, layered scans, dirt, fragmentation, and unstable layouts entered mainstream graphic design in the 1990s, with David Carson’s art direction of Ray Gun from 1992 to 1995 becoming a prominent reference for expressive, rule-breaking editorial typography.

## Design principles and implementation

Use these principles to write a focused AI UI design prompt instead of asking for a vague visual treatment.

Use dirty charcoal, rust, olive, burgundy, faded denim, and nicotine cream with low-chroma highlights and occasional raw warning color. In a daisyUI theme, use rust or burgundy for `primary`, faded denim or olive for `secondary`, and assign nicotine cream, stained beige, and muddy taupe to `base-100`, `base-200`, and `base-300`.

Choose scratched photography, distressed posters, concrete, metal, dust, stains, and weathered fabric with believable material wear.

Keep content medium to high, using texture around groups while protecting text interiors from excessive noise and contrast loss.

Use brief film flicker, scratch passes, rough judder, dust, and torn reveals sparingly so the interface feels worn rather than broken.

Use chipped rectangles, rough masks, uneven borders, stains, tape, and worn edges with little clean geometric perfection. In daisyUI themes, set the `--radius-*` variables to `0` or `0.25rem`.

Reserve distressed, eroded, or metal-inspired type for large headings, then use a sturdy condensed sans or serif for all detailed reading.
